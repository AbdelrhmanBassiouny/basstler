# interaction-model - standing rules

- A message telling the session or the user what failed and what to do next is an explanation or reaction from this model, never a hand-built string.
- A command shown to anyone is a Command value, rendered alone on its line in a fenced bash block.
- A choice always marks one option as recommended and says why.
- A port moves one module per pull request and deletes the hand-built guidance it replaces.
