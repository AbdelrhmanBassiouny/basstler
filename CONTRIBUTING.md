# Contributing to basstler

Contributions are welcome: open an issue to discuss a change, or a pull request against
`main`.

## Licence of contributions

basstler is licensed under the [Apache License 2.0](LICENSE). As its Section 5 states, any
contribution you submit for inclusion is licensed under the same terms, with no further
agreement needed. You keep the copyright on your contribution.

Submit only work you have the right to license this way. If your employer may hold rights
to what you write, make sure they allow you to contribute it.

## Making a change

- Follow the code rules in [AGENTS.md](AGENTS.md).
- Set up the environment and run the tests as described in
  [Developing it](README.md#developing-it). Every change is covered by tests.
- Label the pull request `release:minor` for a new feature or capability, `release:major`
  for a breaking change, or leave it unlabelled for a patch (see
  [Releasing](README.md#releasing)), and say which and why in the description.
